# 독일·스페인 10박 11일 여행 대시보드 (2027.03.20–03.30)

2027년 3월 20일~30일, 독일 슈투트가르트 결혼식과 스페인 리오하(아로)·바르셀로나 일정을 한 장에 모은 대시보드입니다.

- 웹에서 보기: https://einxjin.github.io/trip-2027/

## 파일

- `index.html` — 일정·예약 준비·경비 요약·현지 확인사항을 담은 단일 파일 대시보드 (외부 빌드 없이 브라우저에서 바로 열림)
- `.nojekyll` — GitHub Pages가 Jekyll 처리를 거치지 않고 파일을 그대로 게재하도록 두는 빈 파일

## 수정 방법

`index.html`을 고쳐 같은 브랜치(`main`)에 커밋하면 몇 분 안에 웹 페이지에 반영됩니다.
